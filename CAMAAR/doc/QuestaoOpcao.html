    class QuestaoOpcao

    Modelo que representa uma opção de resposta para questões de múltipla escolha.

    Uma opção pertence a uma questão e pode ser selecionada pelos usuários ao responder formulários. Suporta controle de versões através do campo agrupamento.

    @example Criar uma opção de resposta

    opcao = QuestaoOpcao.new(
  questao: questao,
  texto: "Opção A",
  ordem: 1,
  versao: 1,
  status: "ativo"
)

def set_agrupamento_inicial
  update_column(:agrupamento, id)
end

    Define o agrupamento inicial após a criação da opção. Este método é chamado automaticamente pelo callback after_create quando o agrupamento não foi definido previamente.

    @return [void] @note Efeito colateral: atualiza o campo agrupamento no banco de dados
