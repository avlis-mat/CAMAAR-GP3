    class TokenSenha

    Modelo que representa um token de segurança para ativação ou redefinição de senha.

    Tokens são gerados automaticamente e possuem tempo de expiração. Tokens de ativação expiram em 48 horas, tokens de redefinição em 24 horas.

    @example Criar token de ativação

    token = TokenSenha.new(
  usuario: usuario,
  tipo: "ativacao"
)

def gerar_token
  return if token.present?
  # Gerar token seguro e único
  loop do
    self.token = SecureRandom.urlsafe_base64(32, false)
    break unless TokenSenha.exists?(token: token)
  end
end

    Gera um token seguro e único antes da validação. Este método é chamado automaticamente pelo callback before_validation.

    @return [void] @note Efeito colateral: define o campo token com um valor aleatório único

def set_expiracao
  return if expiracao.present?
  # Ativação: 48 horas
  # Redefinição: 24 horas
  self.expiracao = case tipo
  when 'ativacao'
    48.hours.from_now
  when 'redefinicao'
    24.hours.from_now
  else
    24.hours.from_now
  end
end

    Define a data de expiração baseada no tipo de token. Este método é chamado automaticamente pelo callback before_validation.

    @return [void] @note Efeito colateral: define o campo expiracao:

    - 48 horas a partir de agora para tokens de ativação
- 24 horas a partir de agora para tokens de redefinição
